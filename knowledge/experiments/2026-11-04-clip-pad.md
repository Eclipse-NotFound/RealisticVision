## 1. 改动内容

`refreshMask` 增加 pad 参数（默认值=原常量，敌人单位掩膜语义不变——血条/动画余量保留）；`applyWorldVisual` 对弹体/手臂栅格传紧致 **1/1/1**，内部六处坐标映射（rx/ry、supportX/Y、drawX/Y）与 uniformLit 模糊半径守卫同步参数化。支持区由 bbox 外扩 5×5 瓦片收至 3×3 瓦片。

- 基线：v0.34.7-clip-hyst 冻结源（`legacy-v0346-base/production/src`）；上轮产物目录全部移入 legacy，基线重冻结。
- 可审阅补丁：[production-pad.patch](../../tools/boundary-opt2/production-pad.patch)；准确生产源 `build/boundary-opt2-20261104/production/src`。

## 2. 等价与行为检查（pad-exact-03，8,598 项全部通过）

- **弹体路径像素零差异**（dynDiffs/dynLost/dynAdded 全 0）：收窄只裁掉 bbox 外围缓冲，bbox 内裁剪边界（由遮罩场 alpha>0 决定）逐像素不变——比"允许过渡带差异"更强的正确性证据。
- **支持区收缩阳性**：worldMasks 栅格子格总面积 **15,360 → 6,912（−55%）**。
- 96 组场（FOV/探索/雾场/视野场）严格相同；非弹体静态路径严格相同；8,000 射线回归一致。
- **迟滞保留**：两版边界振荡序列逐位一致（`222222 1111 …`），均 0 次 0↔1 直接翻转；标定均为 `1→2→0` 渐进（v0.34.7 修复在两版同时生效的旁证）。

## 3. S2 组合场景与性能（pad-perf-01 ABBA / 02 BAAB / pad-aa-01 同字节 AA）

新增 **edge-move-idle / edge-move-fire** 场景（方案 S2：玩家往返移动 + 假人边界振荡 ±80px + LMG 开火——FOV 级联、弹体跨界、敌人掩膜全激活的最重组合）。八场景 × 每版本两窗 × 两轮 + AA 轮。

- **RV AS3 计时**：两轮方向不一致（edge-fire R1 +10.6% / R2 −5.6%；edge-move-fire R1 +0.8% / R2 −9.1%），而**同字节 AA 槽差本身 ±5.3%**（fire-move +3.2%、edge-fire −5.3%）——**差异在噪声带内，无可确认收益也无恶化**。训练室弹体栅格绝对工作量小（每帧少量 raster、位图小），分配节省的亚毫秒量被计时噪声淹没。
- **完整帧**：全部场景 ±0.2% 内持平；P95 方向混合。
- 机制收益（子格分配 −55%、GC 压力下降）预期在重负载场景（大量弹体+多敌人掩膜）才可能显现，如实不作帧率声明。

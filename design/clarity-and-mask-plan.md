## 0. 结论速览

| 反馈 | 归因 | 方案 | 实测（离线 A/B） |
|---|---|---|---|
| ①门窗边界远不如墙 | 墙边界 = 原生 40px 角点场（双线性）；门窗光锥边界 = 子格二值（近 200 级落差/10px） | **P1** 覆盖率场（瓦片级 lit 占比 → 瓦片角插值 → 逐子格混合） | 原始场最大步 198→99，显示场 54→37；锥内/锥外/单位遮罩场逐像素或逐字节不变 |
| ②子弹遮罩不完全 | 只沿中轴采样 ⇒ 法向一侧在暗处也整幅放行；固定 10px 步长对短弹体太粗 | **P2** 法向 5 点采样 + 逐段法向宽度收紧 + 自适应步长 | 横向块：基线整条摘罩（漏 30px），候选停在交界前 5px；短弹体边界误差 10px→4px |
| ③移动时边界质量不如 0.9.3 | CS 0.9.3 时期 RV 是 8 子格（5px）；v0.34.0 改成 4 子格（10px） | **P3** 恢复 `fog_vision_quality=1` | 同一基线 fs=8 显示场最大步 31 vs fs=4 的 54（−43%），这是"移动时跳变变粗"的主因 |

三条都带独立配置回滚口；`aperture_edge_aa=0` 时与本轮前**逐像素等价**（60 帧移动对照）。

## 1. 为什么墙平滑而门窗不平滑（结构性对照）

```
墙   ：原生 Tile.visi 每瓦片角 1 个样本 → lightBmp 1px/角 → 显示放大 40 倍双线性
       → 边缘是一条 40px 宽的连续坡；再加 Tile.updVisi 的 +0.1 迟滞 ⇒ 移动时"滑"
门窗 ：RV 自己的 DDA 子格（10px）→ 锥内恒值、锥外记忆/未探索
       → 边缘是二值台阶，落差 = |aL - aD| 最大可达 198 级
```

`v0.35.0` 已让门窗**叶面**走原生角点场（`aperture_surface`），但**光锥区**仍是子格二值，
所以"门后那块亮区的外轮廓"仍然是硬边。P1 就是把光锥区也换成角点场同构的连续覆盖度。

## 2. P1 `aperture_edge_aa` 设计

1. **覆盖率来源**：`recalcTile` 本来就在逐子格算 `lit`，顺手数 `lit>0` 的子格数 ⇒
   `cov = litN / fogSub²`（瓦片级，零额外射线）。只数几何可见性，**不乘透射率**
   （窗 lit=0.8 若参与覆盖率，整条锥的覆盖率只有 0.8，会把锥内也拉暗——第一版踩过）。
2. **瓦片分类**（`aaCls`）：0=暗、1=逐子格候选（光锥边缘）、2=整瓦全亮、3=墙/透光叶面（不参与）；bit2=门景口径。
   判定用中心射线 `litArr`：`0<lit<0.999` ⇒ 候选（穿过透光格），`>=0.999` ⇒ 全亮，`==0` ⇒ 暗。
3. **角点插值**：`cov(corner)` = 共享该角的 4 个瓦片覆盖率平均（跳过类别 3）⇒ 与原生墙场同构。
4. **混合**：逐子格 `a = round(cov*aLit + (1-cov)*aDark)`；
   `aLit` 用 recalcTile 同公式（门景 `doorgrade` 渐变、普通瓦片 `dim` 下限）、`aDark` 用 `dimA` / 255。
5. **被动瓦片**：暗瓦片自己覆盖率 0，但角插值非 0，所以候选瓦片的 8 邻也参与填充
   （它们的 `litT` 借用邻接候选瓦片的最亮值，并继承门景口径）。
6. **只写 `fogCache` 的 alpha**：`currentSight`（单位遮罩）与弹体裁剪用的二值场不动。

成本：候选瓦片 + 1 圈邻接 × fs² 次算术，无新射线、无位图读；整帧差在噪声带内。

## 3. P2 `proj_clip_2d` / `proj_clip_step` 设计

原实现（v0.35.2）：沿弹体轴向分段，只测中轴点 `pointLit(cx+dx·t, cy+dy·t)`，
亮段画成**整幅法向宽度** `[pmin,pmax]` 的四边形。

1. **法向 5 点**：每段在 `[pmin,pmax]` 上等距取 5 点，得到 bitmask，取**最长连续亮子段**
   → 段宽 `[n0,n1]`；同一 run 内取交集（只画"整段都确定是亮"的宽度）。
2. **段宽变化 >2px 就断开**：避免把梯形当矩形。
3. **`anyDark` 语义修正**：段宽被裁（`n0>pmin` 或 `n1<pmax`）与"整段全暗"都必须计入
   `anyDark`，否则"一部分亮、一部分全暗"的弹体会被判成"全亮"而整条摘掉遮罩。
   （这是我自己第一版的 bug，被离线夹具 E4 抓住。）
4. **步长自适应**：`step = min(tile/fogSub, max(4, extent/6))`，段数 ≤96；短弹体从 2~3 个采样点提到 6+。

`projRunBuf` 由 96 个 Number（每段 2 个数）扩到 256（每段 4 个数：`t0,t1,n0,n1`）。

## 4. P3 画质恢复

`fog_vision_quality=0 → 1`：4 子格（10px）→ 8 子格（5px），即 ≤v0.33.17（CS 0.9.3 时期）的网格。
代价是雾/遮罩位图面积 ×4（v0.34.0-fx-liberation 当初正是为此改小）。
本轮**不重新声称帧率**；觉得卡的逃生口是这一行改回 0，P1/P2 不受影响。

## 5. 回滚口

| 键 | 默认 | 0 = |
|---|---|---|
| `aperture_edge_aa` | 1 | 门/窗光锥回到二值硬边（与本轮前逐像素相同） |
| `proj_clip_2d` | 1 | 弹体只按中轴 1 点采样（v0.35.2 行为） |
| `proj_clip_step` | 1 | 固定 1 子格步长（v0.35.2 行为） |
| `fog_vision_quality` | **1** | 4 子格（v0.34.0 起的默认，省像素） |

## 6. 验收（用户侧 3 分钟）

1. 重启游戏；若 RV 是关的（存配置 `enabled=0`），按 **F11** 打开。
2. 找一扇关着的木门/一扇窗，站在侧面看锥形边界：应当是一条有厚度的坡，而不是一刀切的边。
3. 站在亮区朝阴影边界斜射（实弹 + 激光）：弹体侧翼压在阴影里时不应整幅透出。
4. 沿走廊横移：阴影边界应逐像素滑动，不再按 10px 台阶跳。
5. 如果觉得掉帧：`fog_vision_quality=0` 重启（只退网格画质）。

# D53：单人轻机枪射击调查

针对用户反馈“单独开枪即明显卡顿”，武器轻机枪、模式 current。准确基线仍为 D44 的 `build/combat-render-output/production-final2/src`，不使用含 authority 开发的 HEAD 构建正式包。

`run.py` 在独立游戏副本、唯一 AIR ID、隐藏桌面、静音和共享测试登记下运行。读取正式 ModLoader 资源策略并标记并行 AIR；不关闭玩家试玩，不写玩家存档。`--full` 加载当前启用组合，省略时仅探针和手动驱动的 RV。测量完整相邻帧回调间隔，嵌套函数计时不相加。

- 默认：站立/轻机枪原生连射，以及诊断性跳过特效遮罩；`--split` 增加禁用特效鼠标交互、计算后暂撤遮罩。撤罩会改画面且重复拆装，不能作为独占成本或发布候选。
- `--plain` 不插入 RV 内部函数计时。仍保留外层更新计时、原生开火计数、弹体/粒子/缓存观察。
- `--candidate` 比较 D44 与 early-dark 候选；`prepare.py` 从冻结 D44 只增加完全透明支持区的提前判定，`check.py` 做严格图像和阳性检查。候选暂未采用，不能根据像素通过自动部署。
- `--bursts` 记录全部帧，不预热丢弃首次开枪；每120帧中第60–89帧扣扳机。`--reverse` 把新进程首次开火换成关闭 RV，区分首次资源加载与模组成本。

每个名字只能运行一次，失败目录也保留。测试枪只在独立新角色中降低使用等级、补满弹药/耐久，实际攻击、弹体、特效、物理和原生世界继续运行。训练房有原生单位，未新增敌人不等于空场。不得将这些测试设置发布。

01 编译失败；02 被原生等级限制拦截、没有开火；03 修正夹具后有效；04 创建只读媒体硬链接被权限拒绝、没有 AIR；05/06/07/08 后续结果见报告 `knowledge/experiments/2026-10-28-solo-fire.md`。所有失败保持原样。

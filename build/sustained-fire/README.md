# D54：正式存档轻机枪持续射击调查

用户现场：正式启动器、current、轻机枪持续扫射、最大化窗口。准确基线是 D44 v0.33.10 的 `build/combat-render-output/production-final2/src`，不从含 authority 开发的 HEAD 打包。当前安装是否更新，以本轮报告和部署回执为准。

## 测试入口

`run.py <新名字> --full --plain --sweep --solo --native-screen --private-visible`：独立副本、唯一 AIR ID、静音、共享测试登记，复制玩家存档种子到独立存储。通过原生 `ctr.keyAttack` 连续开枪，保留保存的 5 级 lmg；弹药只补到容量，耐久在每窗开始恢复。测试会重新生成同类 random_mane 房间，不能称为重放玩家当时的精确现场。`--solo` 仅在自有副本移除其他单位并固定玩家位置；弹体/粒子/物理仍按原生流程运行。

默认是 idle/off/normal/noeffects 诊断；`--candidate` 是同进程往返配对，`--reverse` 反转顺序，`--both` 增加 classic。`--integer-v2`、`--integer`、`--current-only`、`--v2` 指定候选，不传则为最早 trailing。每窗预热90帧、采样180帧，排除无下一次回调的末帧。局部 RV 更新和完整间隔分开，不把剩余时间独占归因 GPU/GC。

`--native-screen` 的内容区为 2560×1521，近似本机最大化尺寸；`--private-visible` 在独立、不切换的桌面内明确打开本测试窗口并回读 `nativeWindow.visible`。不会出现在用户桌面，不等于真人前台交互验收。`--large-screen` 为1920×1080。早期14轮只改描述符，实际窗口仍隐藏，不能混作真实绘制性能证据。

`check.py <新名字> --integer-v2`：721项严格 ARGB 比较，先完整覆盖整数对齐，再覆盖八种缩放和非整数平移；必须实际触发候选路径。`native_check.py <新名字> --integer-v2`：888项真实原生效果、滤镜、遮挡和恢复检查。

## 冻结候选与失败

输出位于被忽略的 `build/sustained-fire-output/`；每个名字只能运行一次。生成候选脚本也是一次性冻结工具，不能重跑 `prepare.py`（会覆写本轮后来完善的检查入口）。失败目录保留，不用通过结果替换失败证据。

- trailing / trailing-v2 / trailing-current：只裁右下，图像通过；显式显示窗口后收益约2%，没有稳定长帧改善，未采用。`production/` 的 v0.33.11-trailing-cache 是未采用产物，不能安装。
- scroll：滚动矩形裁四边，严格图像失败。
- integer：只在current、父层到屏幕恰好1:1整数平移、无滤镜时裁四边，并保留一格余量；其它情况原路径。19轮361项、23轮扩大至721项通过，20轮约4.4%均值改善但长帧未改善。
- tight / grid / cell：进一步压缩余量，分别在第120/121/121帧严格图像失败，不能采用。
- integer-v2：保留 integer 的几何，去掉临时矩形、同一同步 worldPass 内复用父层变换判断。25轮721项、26轮888项通过；性能结论以报告最终记录为准。
- pixel-cache：预绘并共享1:1完整遮罩，29轮721项通过；30轮整帧仅小幅均值优势、P95更差、局部更新增加，不采用。direct-cache与direct-v2直接使用Bitmap替代，31/32均在f121失败。

27的integer-v2完整射击current回退，未采用。28的最大化显示窗拆分支持继续查特效遮罩绘制，鼠标交互无收益；所有撤罩仅用于诊断。正式仍D44，主源码与release没有修改。本轮没有完成性能修复。

## 存储与发布边界

`player-seed/` 和 `player-evidence/` 是本轮私有只读副本，不提交、不共享、不写回 `%APPDATA%/pfe`；报告只保留必要的场景、指纹和统计。测试原生输入、资源策略和材料硬链接都只作用于本轮实例。

`package.py` 当前绑定最早的 trailing-current 未采用产物。`deploy.py` 需要准确包的 `gate/verified.json` 才能定向替换，并有旧638E指纹、新备份和失败回滚；不能凭图像通过运行部署。若采用其他候选，必须新建包目录、绑定其源、验证准确生产字节后再更新门禁。

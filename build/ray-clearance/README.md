# D51：通透矩形的保守证明

独立从准确D44生产源派生，不叠尚待性能判断的D50。按原遮光快照建立正值/异常值计数的二维累计表。仅整片包围矩形计数为零时，省略原射线逐格遍历；门、水、墙、非有限值以及不匹配的坐标走原算法。原快照仍每帧检查，写入前立即使累计表失效，完整检查成功后再重建。

本轮用户保留试玩，只进行代码和功能/画面对照。射线结果、视野、探索和显示必须严格相同；测试中的命中/步数计数只能证明路径被使用，不能替代完整战斗收益。独立性能与部署仍暂停，尚无采用结论。默认不加载或改动其他模组开发源。

当前候选`candidate-v2`：静态审查时修正换地图后相同数组长度但行宽不同的残留边框风险，未测试的首稿保留并标记不采用。`rays-02`在5种尺寸、空场/墙/半透门/水/异常值等6类输入中完成21129条射线严格对照，134827项通过；含同格、边缘、非批处理、坐标不匹配和中断恢复。首轮只对候选注入中断导致一项错误比较，rays-01保留；修正为双方同样中断后复验，生产候选字节未改。

`validate.py`仅提供功能入口。`native-build <新名称> --large`构建当前安装组合的隔离大地图画面对照，`native-run <名称>`保留试玩，不把计时视为性能证据。构建/启动均按共享登记排队。不得覆盖旧目录；独立性能恢复前不要为此新增或运行性能入口。

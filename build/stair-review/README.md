# D30 独立像素复核

由 RV (3) 在用户允许协调后执行。RV (2) 提供真实 AIR 捕获，本目录仅离线读取，不启动游戏、不修改产品、不操作提交索引。

- `analyze.py <capture> [--detail]`：按原生瓦片高度和材质 alpha 确定允许变化区域，严格核对材质/区外不变、原雾参考及隐藏覆盖层参考。原结果保留，不能把诊断失败删除或提高容差。
- `residual_audit.py <capture>`：进一步比较旧版与候选的隐藏覆盖层残差；结果写入 `build/stair-shadow-output/review-rv3/*-residual-comparison.json`，逐个输入记录 SHA256。

运行环境为本机 Python、NumPy、Pillow；路径参数相对当前目录。有效最后捕获为 `build/stair-shadow-output/reproduction-isolation`。旧严格检查18通过/8失败、隔离检查4通过/4失败始终保留。

## 独立结论（2026-10-19）

八组均把500个错误全黑空气像素降至0，材质及修正区外逐像素不变。默认常亮关闭的四组与保持裁切的原雾参考相等。常亮开启仍有34/70/34/70个像素与隐藏覆盖层的参考相差1/255，既有正差也有负差。

进一步离线核对发现：目标区域所有正1差异像素的最终输出与旧版完全相同，变化发生在隐藏覆盖层后的参考图。明确清空的原生空气区域（x480–639、y640–679、前景alpha=0）在current旧版与候选中都出现完全相同的-2/-1/+1隐藏层差异，最终输出也相等。该诊断操作并非已证明不会改变其他合成取整的参照，不能只凭非零差就断言修补黑影溢出。

可以合并这处局部阶梯分类修复；没有证据要求为自加的严格相等断言扩大产品修改。每个负1残差的具体绘制成因仍未单独证实，不能说全部像素断言全绿或均已证明是抗锯齿。保留诊断边界，不追加AIR。

此结论只覆盖D29派生的325A0DDC…6770A92候选。正式安装已独立升级为D31 DECCA3E0…C4A0B10CA，阶梯候选不能整包覆盖。统一实现/发布方应把局部高度判断合入最新准确生产源再验证；本独立审查不构成新版部署完成的证据。

# D50：复用 classic 私有插值输入

独立基于准确D44生产源，不叠D49同值设置。普通房间（≤48×25）的一代逻辑视野只生成一次classicLogicRaw和classicLogicVisibility；只在第一次真实查询时生成。后续查询仍按旧版相同4×4对齐范围、相同顺序做墙角修正和fogCache发布。大房间保留原局部绘制，不为了复用提前扩大可见范围。

失效与原classicLogicTiles同代：输入光照/逻辑记忆/墙场变化及释放时清除标志。只复用私有插值图，不复用对象分类、不改变动画帧率、画质或查询范围。

预测：如果重复插值是classic主要可优化的成本，保持严格像素一致后，完整六敌战斗应减少帧间隔。小房间当前模式代码未改，是同进程参考；不能将其它模式/大地图未覆盖的收益写成已实现。

checks-plan.json先运行6529项查询序列差分，再运行普通训练房8组全雾/逻辑/遮罩检查；不执行额外全图查询来美化对照。combat-plan.json沿D49的完整加载、隔离存储、共享登记、受控真实AI/SMG、off/normal/candidate正反顺序及210预热/180采样。只读素材与D48结束实验同哈希硬链接，禁止原位修改；宿主和模组包单独复制。

输出build/classic-inputs-output；未通过完整性能与发布门禁前不安装。旧目录不重建覆盖。
